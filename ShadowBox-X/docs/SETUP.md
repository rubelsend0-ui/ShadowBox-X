# Setup
1. Install JDK 17 and Android Studio (SDK 34).
2. File > Open > this folder; wait for Gradle sync.
3. Run on a device/emulator (Android 8.0+). Biometrics need an enrolled fingerprint/face.
4. CI: push to GitHub; download the `ShadowBox-X-debug-apk` artifact from the Actions run.
5. First launch: create master lock, save the recovery key, then import files.
